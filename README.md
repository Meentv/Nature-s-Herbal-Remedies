# Nature's Herbal Remedies

A simple responsive herbal products landing page and enquiry interface.

## Included

- `index.html` — main product page
- `style.css` — original green visual style plus small additions
- `assets/images/` — all product images stored locally (no external image links), resized and compressed for fast loading

## Contact

## Run locally

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173` and visit the project folder.
