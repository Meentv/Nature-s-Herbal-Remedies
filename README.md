# Nature's Herbal Remedies

A simple responsive herbal products landing page and enquiry interface.

## Included

- `index.html` — main product page
- `style.css` — original green visual style plus small additions
- `assets/images/` — supplied product images renamed into an organized folder

## Small additions

- Product category filters: all products, teas, oils & vinegar, wellness, and skin care
- Lazy loading for product images
- Simple WhatsApp shortcut
- Frontend enquiry feedback message
- Improved asset organization and semantic attributes

## Run locally

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173` and visit the project folder.

## Important before launch

- The WhatsApp number `+234 801 234 5678` is the number from the supplied source and should be confirmed before publishing.
- Product names, prices, descriptions, and health claims should be reviewed and approved by the business owner.
- The enquiry form is frontend-only in this version. Connect it to a real email service or backend before production.
- Some original product cards still use remote Pexels image URLs; replace them with approved local images if a fully self-contained build is required.
